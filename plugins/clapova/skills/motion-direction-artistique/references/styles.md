# Sujet → style de départ, et réglages chiffrés

Les ids sont ceux de `plugins/clapova/skills/cadrage/styles/STYLES.md`. La table sujet → style est **proposée** (arbitrage d'après le catalogue) ; le style reste annoncé avec sa raison.

| Sujet | Style de départ | Pourquoi |
|---|---|---|
| Produit haut de gamme, marque | `premium-apple` | beaucoup de vide, une phrase |
| Lancement, promo, chiffres | `reel-motion` | titres cinétiques et compteurs sur plans réels |
| Message fort, budget nul | `kinetic-type` | 100 % code |
| Teaser, sport, tech | `hyper-motion` | plans très courts |
| Éducation, conseils | `listicle` | un point par plan |
| SaaS, appli | `demo-app` | vraie capture, jamais générée |
| Expliquer, B2B | `faceless-explainer` | un bloc visuel par phrase |
| Transformation | `avant-apres` | deux états tenus |

## Réglages (1 = bas, 3 = haut), proposés

| Réglage | 1 | 2 | 3 | Source des valeurs |
|---|---|---|---|---|
| Variance | même gabarit de scène, 1 type de transition | 3 types de transition | 5 types de transition, cadrages variés | 3 à 5 types par film (HyperFrames motion.md) |
| Intensité du mouvement | dépassement 0 %, `std`, `slow` | 5–10 %, `enter`, `base` | 15–25 %, `expressive`, `spring.pop` | Lottie (tiers), tokens §3.1 |
| Densité d'information | 1 ligne à l'écran, plans 2,5–3,5 s | 2 lignes, plans 1,5–2,5 s | 3 lignes max, plans 1–1,5 s | BBC 3 lignes (officiel), §3.3 |

En notoriété, densité 1 (au plus une ligne, pas de mur de chiffres) ; en conversion, accroche écrite courte, prix, CTA (synthèse C6).
