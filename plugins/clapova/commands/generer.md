Avec le serveur MCP Clapova et le skill `clapova:generate`, crée ce média : $ARGUMENTS

1. `get_credits` d'abord. Si le solde ne suffit pas, arrête-toi et dis-le.
2. Choisis le bon outil (`generate_image`, `generate_video`, `generate_voiceover`, `generate_music`, `edit_image_precise`) ; pour un clip vidéo, soigne le prompt (`clapova:prompts-video`) ; pour un lot de plus de 3, `estimate_plan` avant.
3. Montre le résultat (aperçu ou lien) et le coût en une ligne, puis propose une seule suite utile (animer, monter, décliner).
